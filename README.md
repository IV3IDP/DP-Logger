DP Logger for TCI radios is a simple contest logger application designed to manage the log, with integrated Voice Keyer to automate the transmission of pre-recorded voice messages.
It is useful for managing SDR (Software Defined Radio) equipment, such as radios running software like Thetis or AetherSDR by leveraging the TCI server. It can also broadcast, the xml information in N1MM format, on a UDP port, so you cann integrate with other sofware, e.g QSOCapture by SQ3RX, to record the audio, during a contest. The audio recorder management it's also self contained in the software in Wav or Mp3 format, fow every contact logged.
